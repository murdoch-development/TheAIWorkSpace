## Code Philosophy & Engineering Principles - MANDATORY

Before writing or modifying any code, you MUST:

1. **Load engineering principles** — ALWAYS load **`engineering-principles`** first.
   This covers SOLID, DRY, KISS, YAGNI, testing, code organization, and anti-patterns.
   These are requirements, not suggestions.

2. **Select the relevant philosophy** based on your task:
   - Working on UI/frontend? → Load **`frontend-philosophy`** (The 5 Pillars of Intentional UI)
   - Working on backend/logic? → Load **`code-philosophy`** (The 5 Laws of Elegant Defense)
   - Working on both? → Load both

3. **Load the skills** using the `skill` tool BEFORE implementation

4. **Verify your implementation** against ALL checklists BEFORE completing

5. **Refactor if needed** - if code violates any principle, fix it before proceeding

This is NOT optional. These principles define how code must be written in this project.
